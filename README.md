# Gerenciamento Financeiro Pessoal

Projeto acadêmico desenvolvido em Java para gerenciamento de finanças pessoais.

## Tecnologias
- Java
- Maven
- JPA / Hibernate
- MySQL
- Java Swing

## Estrutura
- `model`: entidades
- `dao`: acesso a dados
- `view`: interface gráfica
- `util`: configuração JPA

## Configuração local
1. Crie o banco MySQL `gerenciadofinaceiropessoal`.
2. Configure usuário e senha locais em `src/main/resources/META-INF/persistence.xml`. O valor da senha no repositório é apenas um marcador. **Não publique sua senha real.**
3. Abra o projeto em uma IDE Java com suporte a Maven e execute `view.Main`.

> Projeto para fins de estudo e portfólio.
